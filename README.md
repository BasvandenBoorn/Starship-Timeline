# Starship Production Timeline

**Starship and Booster timeline tracker to view the production and testing progress.**

An interactive, web-based production timeline for the assembly, testing, and launch of SpaceX Starship vehicles (Boosters and Ships).

🌍 **Live website:** [starship-timeline.site](https://starship-timeline.site)

## 🚀 Features
* **Interactive Timeline:** View the progress of each Starship vehicle by phase (Stacking, Outfitting, Cryo Proof, Raptor Integration, Launch-pad tests, and Flight).
* **Smooth Navigation:** Drag to pan and use scroll, pinch, or the provided buttons to zoom in and out.
* **Stacking Pace:** Compare the assembly speed of different vehicles in a clear chart.
* **Filters:** Hide specific production phases, tests (like Static Fire or Cryo), or forecasts by clicking items in the legend.
* **Screenshots:** Instantly generate and download a PNG image of your current view using the built-in screenshot button.
